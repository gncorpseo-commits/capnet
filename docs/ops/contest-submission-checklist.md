## 2. 미확인 항목과 무응답 대비

회신이 오든 안 오든 **양쪽 다 만족하는 준비**만 적는다. "회신 오면 그때 정함"은 금지.

| # | 미확인 | 최악 가정 | 양쪽 만족시키는 대비 | 비용 |
|---|--------|-----------|----------------------|------|
| **U1** | 결과보고서 지정 서식·분량·파일형식 | 지정 서식 있음 · 한글(hwp) 요구 · 쪽수 제한 | 본문을 **절 단위 독립 블록**으로 작성(순서를 바꿔도 말이 되게). 원본은 `.md`로 두고 제출본은 **pdf + docx** 생성. 서식이 뒤늦게 나와도 텍스트 기반이라 한글로 옮기는 데 30분 | 낮음 |
| **U2** | 소스코드 제출 형식 (repo URL / zip) | zip 필수 + 업로드 용량 제한 | **태그 + GitHub Release**로 URL과 zip을 동시에 확보. `git archive`로 `.git` 제외 zip 별도 생성. 압축본 **50MB 이하** 유지 | 낮음 |
| **U3** | 라이선스 검증 제출 산출물 | 요구됨 · 정해진 서식 있음 | NOTICE · THIRD-PARTY-LICENSES.md · SBOM(CycloneDX) · 가중치/데이터 출처 선언 1쪽을 **선제 동봉**. 요구가 없어도 감점 요인이 아니고, 있으면 그대로 낸다 | 중간 |
| **U4** | 영상 제출 방식 (파일 업로드 / 링크) | 파일 업로드 · 용량 제한 · 무음 재생 | mp4 파일과 **비공개 링크 둘 다** 준비. **자막 번인**(소리 없이 봐도 이해되게). 1080p / H.264 / 200MB 이하 | 낮음 |
| **U5** | 심사 PC 사양·인터넷 환경 | 사양 낮음 · 방화벽 · 최초 pull 실패 | compose 이미지 **태그 핀 고정**, 최초 내려받는 용량과 소요를 README에 명시, 필요한 이미지 목록을 별도 표로 | 낮음 |
| **U6** | 제출 후 수정 가능 여부 | **불가** | 내부 마감을 **8/26 12:00**으로 당긴다. 8/27은 예비일로만 쓴다 | 무료 |

문의 메일은 오늘 보내되, 위 6건은 **회신과 무관하게 그대로 실행한다.** 회신이 오면 준비된 것 중 해당 항목만 골라 내면 된다.

## 3. 제출물 3종 준비 목록

### 3.1 결과보고서 (M22) — 1차 통과가 여기서 갈린다

서식이 없다는 가정의 기본 목차. 서식이 오면 블록만 재배치한다.

| 절 | 내용 | 필수 삽입물 |
|----|------|-------------|
| 0 | **한 쪽 요약** — 문제 / 해법 / 증명한 것 / 재현 한 줄 | 없음. 심사위원이 이 쪽만 볼 수 있다고 가정하고 쓴다 |
| 1 | 문제 정의 — **내 데이터가 어디로 갔는지 답할 수 있는가** (라우팅·증적) | — |
| 2 | Capability = 계약 (스키마 + 골든셋 + 게이트) | 계약 예시 1개 |
| 3 | 아키텍처 | **게이트 사슬 다이어그램 1장** |
| 4 | 불변식을 앱이 아니라 **DB로 강제한 설계** | 제약 구조 요약 |
| 5 | **위반 14종 실측 표** ⭐ | `docs/error/pg-violations.md` 표 그대로 + 터미널 캡처 2–3장 |
| 6 | 골든셋과 채점 규칙 — closed-set · AND 조건 · sanity 3종 | 샘플 이미지 1장 |
| 7 | 재현 절차 — clone → compose → demo, 예상 소요와 출력 | 명령 블록 |
| 8 | **한계와 다음 단계** — N=50이면 SE≈0.05로 판정 불가임을 명시 | — |
| 9 | 라이선스 — Apache-2.0 · 사전학습 가중치 미사용 선언 · 의존성 표 | 의존성 표 |

- 8절은 빼지 않는다. 한계를 스스로 적은 보고서가 심사에서 더 신뢰받는다.
- 5절이 이 프로젝트의 유일한 진짜 변별점이다. **가장 많은 지면을 준다.**
- 절마다 200자 요약 문장을 유지한다. 쪽수 제한이 뒤늦게 확인되면 그 문장들만 남겨 압축한다.
- **본문은 2쪽 고정 표다** (공식 예시본 실측). 자유 서술 분량이 아니라 칸 크기에 맞춰 압축한다.
  붙여넣기용 압축본: [`contest-report-form-draft.md`](./contest-report-form-draft.md) 「본문 붙여넣기용 압축본」.
