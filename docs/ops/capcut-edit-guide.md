## 0. 화면이 어디인지

| 위치 | 역할 |
|------|------|
| 왼쪽 세로 탭 | 미디어 · **텍스트** · 오디오 · … |
| 가운데 미리보기 | 재생 화면 |
| 아래 타임라인 | 클립을 **자르고** 자막 트랙을 올리는 곳 |
| 타임라인 **위** 아이콘 줄 | **분할**(가위) · 삭제(휴지통) |
| 오른쪽 패널 | 선택 중 클립/텍스트의 속성(글꼴·크기·색) |
| 우측 상단 **내보내기** | 최종 mp4 |

흰 세로선 = **재생 헤드**(지금 시점). 자르기는 항상 **이 선 위치**에서 한다.

## 1. 자르기 (분할 → 삭제)

### 1-A. 기본 절차

1. 타임라인에서 **영상 클립을 한 번 클릭**해 선택(파란 테두리).
2. 미리보기나 타임라인을 스크롤해, **남기고 싶지 않은 구간의 시작**에 재생 헤드를 둔다.
3. **분할** — 아래 중 하나:
   - 타임라인 위 **분할** 아이콘(세로선으로 클립을 가른 모양), 또는
   - 단축키 **`Ctrl + B`**
4. 같은 방식으로 **구간의 끝**에서도 한 번 더 분할한다.
5. 가운데 **버릴 조각만** 클릭 → **`Delete`** (또는 휴지통 아이콘).
6. 앞뒤가 붙었는지 확인하고, 틈이 남으면 뒤 클립을 앞으로 끌어 붙인다.  
   (버전에 따라 **`Shift + Delete`** = 지우고 뒤가 당겨짐 — 있으면 그걸 쓴다.)

### 1-B. 끝을 살짝만 줄일 때 (분할 없이)

클립 **왼쪽/오른쪽 가장자리**를 드래그하면 앞·뒤가 잘린다.  
「중간만 빼기」는 1-A(두 번 분할)가 맞다.

### 1-C. 정밀하게

- 타임라인 오른쪽 **− / +** 로 확대한다.
- **`←` / `→`** = 한 프레임씩 이동.
- **`Space`** = 재생/일시정지.
- 잘못 자르면 **`Ctrl + Z`**.

### 1-D. 출품 영상에서 자를 때

대략 **1분 20초**를 줄여야 한다. 우선순위:

1. 대기 · 창 전환 · 스크롤 · 실패 재시도
2. 같은 화면이 길게 이어지는 터미널 (중요 줄만 남기거나 배속)
3. 시간 없으면 **A/B 구간 통삭제**, sanity도 짧게 또는 삭제

남길 뼈대는 런북 §1 타임라인(로고 → 생존 → demo → violations → 증적·경계 → GitHub).

## 2. 글(자막) 넣기

출품은 **소리 없이 봐도 이해**되게 해야 한다(체크리스트 V1).  
**자동 캡션만 믿지 말고**, 런북 §2 문장으로 맞춘다.

### 2-A. 추천: 직접 텍스트 (번인용)

1. 왼쪽 탭 **텍스트** (`T` 아이콘) 클릭.
2. **기본 텍스트** → **텍스트 추가**(또는 기본 텍스트 상자를 타임라인으로 드래그).
3. 타임라인에 **자막 트랙**이 생긴다. 막대 길이를 드래그해 **그 장면이 보이는 동안만** 맞춘다.
4. 미리보기/오른쪽 패널에서 문장을 **런북 §2**로 바꾼다.
5. 스타일 (오른쪽 패널):
   - 글자 크게 (터미널과 겹치지 않게 **화면 아래 1/4**)
   - 흰색 + **외곽선/그림자** (어두운 터미널 대비)
   - 한 화면에 **한 문장** (길면 둘로 나누고 타이밍을 이어 붙임)

구간마다 자막을 **새로 추가**하거나, 텍스트 클립을 **`Ctrl + B`**로 나눈 뒤 문장만 바꾼다.

### 2-B. 자동 캡션 (초안용 · 선택)

음성이 있을 때만 의미가 있다. 터미널 무음 위주 영상이면 **2-A가 더 빠르다**.

1. **텍스트** → **자동 캡션**(또는 캡션 → 자동 캡션).
2. 언어 **한국어** → 생성/인식.
3. 생성된 줄을 **전부 검수**하고, 출품 문장은 런북 §2·§2-A로 **교체**.
4. 캡션 블록도 재생 헤드 두고 **`Ctrl + B`**로 나눌 수 있다  
   ([CapCut 도움말: Split subtitles](https://www.capcut.com/help/split-the-subtiltes)).

자동 캡션은 **인터넷**이 필요할 수 있다. Pro 템플릿·유료 효과는 쓰지 않는다(워터마크 위험).

### 2-C. 복붙 문장 (런북 §2)

| # | 자막 |
|---|------|
| 1 | 능력만 요구하면 됩니다. 어떤 AI가, 어느 기계에서 도는지는 몰라도 됩니다. |
| 2 | 그런데 "몰라도 된다"는 "아무 데서나 돈다"가 아닙니다. |
| 3 | 승인하지 않은 신뢰 도메인으로는 DB가 라우팅을 거절합니다. |
| 4 | 앱은 GPU 주소를 통신 계약으로 삼지 않습니다. 계약은 Capability입니다. |
| 5 | 노드도 Core가 배정하지 않은 일은 거부합니다. |
| 6 | 그리고 누가·무엇으로·언제 실행했는지 증적이 남습니다. |
| 7 | 어느 등급에서 어느 등급으로 갔는지도 함께 남습니다 — 배정 시점에 DB가 검증한 값입니다. |
| 8 | 위반은 앱 if가 아니라 PostgreSQL이 REJECTED. |
| 9 | CapNet OSS — compose로 재현. |

A/B를 **넣었다면** 그 구간에만:

- 같은 능력으로 다른 에이전트에 교체 배정됩니다. 계약을 통과한 것만 후보가 됩니다.
- 다만 두 에이전트가 같은 답을 낸다고는 말하지 않습니다.

**금지:** Within · 편차 0.05 · 같은 답/대체 가능.

### 2-D. 「글이 영상에 남게」하는 법

내보내기할 때 자막이 **영상에 구워져** 나가게 한다(번인).  
플랫폼용 소프트 자막만 끄고 보내면, 심사 PC에서 안 보일 수 있다.  
CapCut에서는 타임라인에 올린 **텍스트 레이어가 있는 상태로 그대로보내기**하면 화면에 포함된다.
