# CapNet 사용 안내 (쉬운 버전)

**파일:** `docs/guide/user-guide-ko.md` (영문 파일명 · zip 제출 대비)  
**누구를 위한 글인가요?**  
프로그램을 만드는 방법이 아니라, CapNet이 **무엇을 위해 있고, 누가 무엇을 하면 되는지**만 말합니다.  
IT 지식이 없어도 읽히도록 썼습니다.

**관련:** [Contest MVP 계획](../ops/Contest_MVP_2026.md) · [기획서](../design/capnet-plan.md) · [골든셋](../spec/golden/image-classify-v1.md)

---

## 1. 한 줄로

**CapNet**(Capability Network)은 “어떤 AI 제품인지”보다 **무슨 일을 할 수 있는지**를 기준으로,  
**우리 쪽 컴퓨터**에서 그 일을 **시험에 합격한 AI만** 시키게 하는 시스템입니다.

**우리 쪽 컴퓨터란?**  
회사·팀이 관리하는 PC나 서버입니다. 클라우드에 데이터를 보내지 않고, **우리가 켜 둔 기기**에서 돌립니다.  
대회 데모에서는 보통 **노트북(또는 PC) 한 대**입니다.

비유하면 **학원 시험 시스템**입니다.

| 말 | 쉬운 뜻 | 비유 |
|----|---------|------|
| Capability (능력·계약) | “이런 일을 이렇게 한다”는 **과목 규정** | 시험 과목 |
| Agent | 그 과목을 볼 **AI 모델** | 수험생 |
| Node | 일을 돌리는 **우리 쪽 컴퓨터** | 시험장 |
| 게이트(Gate) | 과목 합격 시험 | 자격시험 |
| Task (할 일) | “이번엔 이것 해 줘” | 실전 한 문제 |
| 골든셋 | 정답이 있는 **연습 문제 묶음** | 기출문제 |

**규칙:** 자격시험에 떨어진 수험생에게는 실전 문제를 주지 않습니다.

---

## 2. ChatGPT 같은 것과 무엇이 다른가

| | 흔한 AI 챗·클라우드 API | CapNet이 겨냥하는 것 |
|--|------------------------|----------------------|
| 질문 | “아무거나 물어보세요” | “이 **과목**만 해 주세요” |
| 어디 컴퓨터 | 보통 회사 밖 클라우드 | **우리 쪽 컴퓨터**(팀 PC·노트북) |
| 모델 교체 | 제품·화면이 바뀌기 쉬움 | **같은 과목 규정**이면 모델만 바꿀 수 있게 |
| 엉터리 모델 | 이름만 그럴듯해도 올리기 쉬움 | **시험 통과 전엔** 실전 불가 |

CapNet은 “또 하나의 챗봇”이 아니라,  
**일을 맡기는 규칙과 시험이 있는 실행 장치**에 가깝습니다.

---

## 3. 왜 “시험”이 필요한가

이름만 “사진 분류기”인 프로그램을 올리면,  
실제로는 엉터리로 답해도 티가 잘 안 날 수 있습니다.

CapNet은 과목마다 **정답이 있는 문제 묶음**으로 점수를 매깁니다.

- 기준 점수 이상 → **합격** → 실전 요청 가능  
- 미달 → **불합격** → 실전 요청 불가  

일부러 “항상 같은 답만 하는” 엉터리 수험생은 **떨어져야 정상**입니다.

데모용 연습 문제 개수는 적을 수 있습니다.  
“통계로 완벽히 증명”하는 큰 시험은 본편에서 하고, 대회 데모는 **시험이 돌아가는지**를 보여 줍니다.

---

## 4. CapNet의 특별한 점 — 잘못된 요청은 “거절”된다

많은 시스템은 규칙을 **안내문**에만 적습니다.  
CapNet은 중요한 규칙을 **장부(데이터베이스)에 잠가 둡니다.**

예를 들면 이런 시도는 **거절**됩니다.

- 시험 안 본 수험생에게 실전 주기  
- “우리 팀만”인 일을 외부 컴퓨터로 보내기  
- 큰 일이 필요한데 너무 약한 컴퓨터에 맡기기  

데모에서 **빨간 거절 메시지**가 보여도 당황하지 마세요.  
그건 버그가 아니라 **규칙이 살아 있다는 증거**입니다.  
거절은 고장이 아니라 **정상 동작**입니다.

---

## 5. 누가 무엇을 하나

### 5.1 사용자 (평소에 일 맡기는 분)

**하시면 되는 것**

1. 과목을 고릅니다. (예: 사진 분류)  
2. **미리 허용된** 사진(또는 번호)을 고릅니다.  
3. “해 주세요”를 보냅니다.  
4. 결과를 봅니다. (예: “숲”)

**몰라도 되는 것**

- 어떤 AI 파일인지  
- 어느 PC에서 돌았는지  
- 시험 점수가 얼마인지  
- **AI가 바뀌어도 요청하는 방법은 그대로**입니다 (과목만 같으면 됩니다)

**이 데모에서 안 되는 것**

- 아무 사진이나 마음대로 올리기 → **허용된 묶음만** 가능합니다.

---

### 5.2 모델 등록자 (AI를 준비하는 분)

1. 정해진 형식의 AI 파일을 올립니다.  
2. “파일이 바뀌지 않았는지” 지문과 함께 등록합니다.  
3. 시험장 컴퓨터에 연결합니다.  
4. **운영자와 함께 과목 시험(게이트)** 을 봅니다.  
5. 합격해야 사용자의 실전 요청을 받을 수 있습니다.

---

### 5.3 운영자 (학원 행정 담당)

1. 과목 규정을 등록합니다.  
2. 시험 문제 묶음을 붙입니다.  
3. 시험장 컴퓨터(우리 쪽 PC)를 켭니다.  
4. 게이트를 진행하고 합격을 확인합니다.  
5. (데모) 규칙을 어기는 요청이 **거절되는지** 보여 줍니다.  
6. (선택) 다른 수험생으로 같은 과목을 다시 시켜 봅니다.

---

### 5.4 처음 보는 분 (심사·동료)

1. 저장소를 받습니다.  
2. “한 번에 실행” 안내(데모)를 따릅니다.  
3. **합격 → 실전 한 건 → 잘못된 요청 거절** 을 확인합니다.

설치 세부 사항은 개발자용 README를 보면 됩니다.

---

## 6. 하루의 이야기

```text
① 운영자: 「사진 분류」과목을 만든다
② 운영자: 우리 쪽 컴퓨터(시험장)를 켠다
③ 등록자: 수험생(AI)을 올리고 연결한다
④ 운영자: 기출문제로 시험 → 합격 / 불합격
⑤ 사용자: “이 사진 분류해 줘” → 결과
⑥ (데모) 잘못된 조합 → 거절 (정상)
```

사용자는 **⑤만** 반복하면 됩니다.

## 7. 자주 묻는 말

**Q. ChatGPT랑 뭐가 다른가요?**  
A. 대화 비서가 아니라, **정해진 과목·시험·우리 쪽 컴퓨터**로 일을 처리하는 장치입니다.

**Q. 우리 회사 비밀 사진을 넣어도 되나요?**  
A. 대회 데모는 **공개·연습용 사진**입니다. 비밀 데이터는 나중에 허가된 단계에서.

**Q. 점수가 조금 다른 두 AI는?**  
A. 둘 다 합격하면 관리 모드에서 바꿔 가며 시킬 수 있습니다.  
일반 사용자는 AI를 고르지 않아도 되고, **요청 방법은 그대로**입니다.

**Q. “거절된다”는 게 고장인가요?**  
A. 아니요. **위험한 조합을 막는 것**이 정상입니다.

**Q. 연습 문제가 적으면?**  
A. 데모는 “시험·거절이 **동작하는지**”용입니다. 큰 통계는 본편에서.

**Q. 에러가 나면?**  
A. 시각·요청 내용을 운영자에게 넘기면 됩니다.

## 8. 한 장으로 요약

| 당신 | 기억할 한 줄 |
|------|----------------|
| 사용자 | 과목·허용된 입력·결과. AI가 바뀌어도 요청법은 같음 |
| 모델 등록자 | AI 올리고 시험 통과해야 실전 |
| 운영자 | 과목·시험장·합격·거절 데모 |
| 처음 보는 분 | 데모로 “시험 → 실전 → 거절” 확인 |

**CapNet = 과목 규정 + 합격 시험 + 우리 쪽 컴퓨터에서 실전 + 잘못된 조합은 거절.**
