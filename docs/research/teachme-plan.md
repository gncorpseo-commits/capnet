# TeachMe Agent — 기획서 (초안)

**문서 버전:** v0.1  
**작성일:** 2026-08-08  
**제품명:** TeachMe Agent (가칭)  
**성격:** CapNet과 **별도 제품**. 이후 CapNet Capability/Agent로 등록·실행하는 확장을 전제함  
**상위 공간:** ai-agent-store (CapNet과 형제 제품 후보)

> CapNet 대회 MVP·스키마와 무관하다. 확정·구현이 커지면 독립 레포 또는 `docs/design/` 이관을 검토한다.

---

## 1. 한 줄 목적

강의(동영상)를 분석·정리해, **해당 강만으로 이해에 필요한 정보를 모두 모은 교재**를 만든다.  
학습자는 **그 교재 안**에서 해당 강 내용을 전부 이해할 수 있다.

성공의 척도는 “잘 요약했는가”가 아니라 **교재만으로 이해 가능한가**이다.

---

## 2. 비목적 (하지 않는다)

| 비목적 | 이유 |
|--------|------|
| N강 교재에 N+1 이후 **심화·확장**을 넣기 | 강의는 1강→2강 순차. 이후 내용은 다음 강 교재의 몫 |
| “알면 좋은” 호기심 탐구를 본편에 섞기 | 호기심 영역은 학습자 자율. 목적을 흐리지 않음 |
| 영상 플레이어·타임라인 UX를 본제품으로 삼기 | 본제품은 **자족 교재 전달** |
| CapNet 스키마·큐·claim을 TeachMe DB에 미리 복제 | 제품과 런타임을 섞지 않음 |

**규칙:** N강 교재 = N강 이해에 필요한 것만. 이후 심화는 다루지 않는다.

---

## 3. 핵심 개념

| 개념 | 정의 |
|------|------|
| **강의 단위** | 보통 1강·2강처럼 순차 에피소드. 교재는 **에피소드 단위**로 생성 |
| **자족 교재** | 원 강의를 다시 보지 않아도, 그 강 범위의 내용을 이해·점검할 수 있는 문서 |
| **필수 보충** | 강의가 암묵한 **선수·전제** 중, 이 강을 이해하는 데 꼭 필요한 것만 보충 |
| **호기심 영역** | 다음 강·심화·응용. 교재 본편 밖 (링크·부록으로만 둘지 여부는 미결) |
| **접근(Access)** | 동영상 URL에서 학습 원본(영상·음성·자막·메타)을 확보하는 단계 |
| **TeachMe Agent** | 위 파이프라인을 수행하는 구현체. CapNet 관점에서는 훗날 **Agent** |

```text
동영상 URL
  → 접근 확보 (실패 시 사용자 협조 또는 공개 경로 재시도)
  → 내용 분석·정리
  → 자족 교재 생성 (해당 강 범위만)
  → 학습자에게 교재 전달
```

---

## 4. 사용자 플로우

### 4.1 기본 경로

1. 학습자(또는 운영자)가 **동영상 URL**을 전달한다.
2. TeachMe가 URL **접속·원본 확보**를 시도한다.
3. 확보된 내용으로 **해당 강**을 분석·구조화한다.
4. 이해에 필요한 정보를 모아 **자족 교재**를 생성한다.
5. 학습자는 **교재만**으로 해당 강 내용을 학습·이해한다.

### 4.2 접근 실패 시 (원칙)

접속이 안 되면 **불법 우회가 아니라** 다음 순으로 본다.

1. 공개적으로 가능한 경로 (공개 페이지, 공식 embed, 공개 자막 등)
2. 사용자에게 **최소 협조** 요청 (로그인·권한, 파일/자막 업로드, 대체 URL 등)
3. 그래도 불가하면 **중단·명확한 안내**

세부 우선순위·지원 플랫폼 목록은 **미결 (§8)**.

### 4.3 학습자 경험 원칙

- 학습자의 주 인터페이스는 **교재**이다.
- 영상은 원본·증빙·재확인용일 수 있으나, **이해의 필수 경로로 두지 않는다**.
- 시리즈는 강 단위로 교재가 쌓인다 (1강 교재 → 2강 교재 …).

---

## 5. 자족 교재 — 넣는다 / 넣지 않는다

| 넣는다 | 넣지 않는다 |
|--------|-------------|
| 이 강에서 다룬 개념·용어·정의 | 다음 강에서 다룰 심화 |
| 논리 전개·단계·핵심 주장 | 시리즈 전체 마스터용 범위 확장 |
| 이해에 필요한 예시·반례 | “알면 좋은” 응용·탐구 (호기심 영역) |
| 이 강 이해에 **필수**인 선수·암묵 전제 | 선수 지식의 무제한 백과사전화 |
| 이 강 범위의 자기점검 (퀴즈·체크리스트) | 다음 강 예습 문제 세트 |

### 5.1 교재 뼈대 (초안 템플릿)

매 강 동일 골격을 유지한다. 세부 항목은 MVP에서 조정 가능.

1. **이 강에서 무엇을 이해하게 되는가** (학습 목표)
2. **선수·전제** (필수 보충만)
3. **본문** (개념 → 전개 → 예시, 강의 순서에 맞춘 재구성)
4. **용어 정리**
5. **요약** (해당 강만)
6. **자기점검** (해당 강 범위)
7. **(선택) 호기심 메모** — 본편과 시각적으로 분리. 없어도 이해에 지장 없음

## 6. 성공 기준

| 기준 | 판정 방향 |
|------|-----------|
| **자족성** | 교재만 주고, 해당 강 범위 이해도 점검에서 기준 통과 |
| **범위 절제** | 다음 강·심화 내용이 본편에 실질적으로 섞이지 않음 |
| **구조 완결** | §5.1 필수 섹션이 비어 있지 않음 |
| **출처 정합** | 본문 주장이 확보된 강의 원본과 모순되지 않음 (환각 최소화) |

정량 루브릭·골든 강의 세트는 MVP에서 정의한다.  
CapNet 연동 시 이 기준이 **게이트/골든셋** 후보가 된다.

---

## 7. CapNet과의 관계

| 단계 | 내용 |
|------|------|
| **지금** | TeachMe를 **독립 제품**으로 기획·구현. CapNet 코드/DDL과 분리 |
| **나중** | TeachMe를 CapNet **Agent**로 등록. Capability 예: `edu.lecture.material@1` (가칭) |
| **게이트** | team gate-runner에서 자족성·범위 절제 루브릭으로 PASSED |
| **Product Track** | 사용자는 Capability만 호출. Agent 선택 UI 없음 |
| **Node** | 분석·생성 실행 기기. trust_domain / compute_tier는 CapNet 규약 따름 |

CapNet 절대 규칙(스키마 약화 금지, safetensors, allowlist 입력, gate-runner 전용 등)은 **연동 시점에** 계약으로 반영한다. TeachMe MVP가 자유 URL을 받더라도, CapNet Capability로 올릴 때는 **계약된 입력**으로 좁힐 수 있다.

```text
[독립] TeachMe 파이프라인
        ↓ (품질·계약 고정 후)
[연동] Capability → Gate PASSED → TeachMe Agent → Assignment → Node
```

## 8. MVP 범위 / 비범위

### MVP에 넣기 (안)

- 단일 강의 URL → 자족 교재 1편 생성·전달
- §5 넣는다/안 넣는다 규칙 준수
- 접근 실패 시 사용자 협조 요청의 최소 1경로
- 교재 고정 뼈대 (§5.1)

### MVP에서 빼기 (안)

- CapNet 실연동·게이트 자동화
- 다중 플랫폼 완벽 지원
- 학습자 장기 프로필·적응 학습 OS
- 실시간 튜터 채팅을 본제품으로
- 호기심 영역의 자동 심화 코스 생성

## 9. 미결

| # | 내용 | 비고 |
|---|------|------|
| O1 | 지원 입력: URL만 / 자막 파일 / 음성 파일 | 접근 전략과 연동 |
| O2 | 접근 실패 시 요청 우선순위·지원 사이트 | 합법·ToS 준수 전제 |
| O3 | 학습자 “수준”을 MVP에 넣을지 | 현 목적상 **자족 교재**가 1순위. 수준 맞춤은 후속 |
| O4 | 호기심 영역을 부록으로 둘지, UI에서 숨길지 | 본편과 분리만 확정 |
| O5 | 자족성 검증 방법 (퀴즈, 루브릭, 인간 평가) | 게이트 초안과 연결 |
| O6 | 독립 레포 시점·이름·스택 | CapNet과 저장소 분리 여부 |
| O7 | Capability `code@version`·입출력 스키마 초안 | CapNet 연동 직전 |
